## 📌 Chapter Overview

Chapter 13 focuses on securing the Salesforce Placement Management System.

A professional Salesforce application must not only determine:

> "What can the system do?"

It must also determine:

> "Who is allowed to do it?"

This chapter focuses on:

- Salesforce Security Model
- Authentication
- Authorization
- Profiles
- Permission Sets
- Permission Set Groups
- Roles
- Role Hierarchy
- Object-Level Security
- Field-Level Security
- Record-Level Security
- Organization-Wide Defaults
- Sharing Rules
- Apex Sharing
- `with sharing`
- `without sharing`
- `inherited sharing`
- CRUD
- FLS
- Least Privilege
- Secure Apex
- Secure LWC design
- Integration Security
- Security Testing
- Security Audit
